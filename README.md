# Credit Card Fraud Detection

## Overview

This project focuses on detecting fraudulent credit card transactions using machine learning. The main challenge is the extreme imbalance between legitimate and fraudulent transactions, making accuracy an unreliable evaluation metric.

The project compares several classification approaches, including:

- Logistic Regression
- Random Forest
- Boosting
- Neural Network

The models are evaluated using **precision, recall, F1-score, and AUPRC**, with additional techniques used to address class imbalance.

## Dataset

The project uses the **Credit Card Fraud Detection** dataset, containing 284,807 anonymised European card transactions, including 492 fraudulent transactions. The dataset contains PCA-transformed features (V1–V28), transaction time, transaction amount, and the fraud classification target.

## Objectives

- Explore and preprocess highly imbalanced transaction data.
- Build and compare multiple classification models.
- Evaluate models using metrics appropriate for fraud detection.
- Investigate techniques for handling class imbalance.
- Identify the model that provides the best balance between detecting fraud and avoiding false alarms.
